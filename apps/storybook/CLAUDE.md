# Storybook App

Component showcase and testing environment for Zetsel packages.

## Development

Run with `pnpm dev` from the root or this directory.

## Story Files

Add `.stories.tsx` files next to components in packages:
- `packages/ui/**/Component.stories.tsx`
- `packages/admin/**/Component.stories.tsx`
- `packages/kanban/**/Component.stories.tsx`

Stories are auto-discovered by Storybook.
