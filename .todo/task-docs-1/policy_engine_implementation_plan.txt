Core Policy Engine — Implementation Plan
Context
The user wants to build a Core Policy Engine inside backend/core/policy_engine/ — a metadata registry that tracks apps, models, endpoints, permission categories, dependency relationships, version history, and audit changelogs. This is the authoritative source of truth for access-control metadata in the system. It does NOT manage users, roles, departments, or permission assignment (those come later in separate apps).

Additionally, CLAUDE.md must be patched to make the policy engine lifecycle a mandatory part of every future endpoint implementation.

This is a Major scope task (schema change, new sub-app, 8 new models, migrations, management commands, API views, tests, documentation).

Prompted by: .docs/policy_engine_prompt.md (1285 lines, sections 1–31).

Architecture Decision
core/policy_engine/ is placed inside core/ as an approved foundational exception to the "no real DB tables in core/" rule. The policy engine is global infrastructure, not app-specific business logic. This must be documented in CLAUDE.md.

INSTALLED_APPS entry: "core.policy_engine"
AppConfig: name = "core.policy_engine", label = "policy_engine" (avoids Django label collision with core)
Migration dir: core/policy_engine/migrations/
URL prefix: /api/v1/policy/
Auth on views: IsAuthenticated + is_staff inline check (per CLAUDE.md §9 interim pattern)

PolicyApplication

class PolicyApplication(BaseModel):
    key = SlugField(unique=True, max_length=100, db_index=True)
    display_name = CharField(max_length=255)
    description = TextField(blank=True)
    current_version = CharField(max_length=50, default="1.0.0")
    is_active = BooleanField(default=True)
    is_deprecated = BooleanField(default=False)
    def __str__(self): return self.key
PolicyModel

class PolicyModel(BaseModel):
    application = FK(PolicyApplication, CASCADE, related_name="policy_models")
    key = SlugField(max_length=100, db_index=True)
    import_path = CharField(max_length=500, blank=True)
    display_name = CharField(max_length=255)
    description = TextField(blank=True)
    current_version = CharField(max_length=50, default="1.0.0")
    is_active = BooleanField(default=True)
    is_deprecated = BooleanField(default=False)
    class Meta: unique_together = ("application", "key")

class PolicyEndpoint(BaseModel):

PolicyDependency

class PolicyDependency(BaseModel):
    source_endpoint = FK(PolicyEndpoint, CASCADE, related_name="outgoing_dependencies")
    target_endpoint = FK(PolicyEndpoint, CASCADE, related_name="incoming_dependencies")
    direction = CharField(max_length=50, choices=DependencyDirection.choices)
    dependency_type = CharField(max_length=50, choices=DependencyType.choices)
    enforcement_mode = CharField(max_length=50, choices=EnforcementMode.choices, default=EnforcementMode.STRICT)
    reason = TextField(blank=True)
    is_active = BooleanField(default=True)
    is_deprecated = BooleanField(default=False)
    class Meta: unique_together = ("source_endpoint", "target_endpoint", "direction", "dependency_type")
    def __str__(self): return f"{self.source_endpoint.permission_key} -{self.dependency_type}→ {self.target_endpoint.permission_key}"
PolicyChangeLog

class PolicyChangeLog(BaseModel):
    # append-only: never update, delete only with explicit approval
    application = FK(PolicyApplication, SET_NULL, null=True, blank=True)
    policy_model = FK(PolicyModel, SET_NULL, null=True, blank=True)
    endpoint = FK(PolicyEndpoint, SET_NULL, null=True, blank=True)
    object_type = CharField(max_length=50, choices=ObjectType.choices)
    object_key = CharField(max_length=255, blank=True)
    previous_version = CharField(max_length=50, blank=True)
    new_version = CharField(max_length=50, blank=True)
    change_type = CharField(max_length=100, choices=ChangeType.choices)
    summary = CharField(max_length=500)
    detail = TextField(blank=True)
    reason = TextField(blank=True)
    issue_reference = CharField(max_length=255, blank=True)
    migration_reference = CharField(max_length=255, blank=True)
    affected_dependencies = JSONField(default=list, blank=True)
    affected_categories = JSONField(default=list, blank=True)
    backward_compatibility_notes = TextField(blank=True)
    forward_compatibility_notes = TextField(blank=True)
    created_by_type = CharField(max_length=50, choices=CreatedByType.choices, default=CreatedByType.SYSTEM)
    created_by_identifier = CharField(max_length=255, blank=True)
    def __str__(self): return f"{self.change_type}: {self.object_key} ({self.created_at})"
